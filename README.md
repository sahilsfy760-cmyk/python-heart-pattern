# python-heart-pattern
A heart pattern generator built in Python using nested loops, conditional logic, and coordinate-based pattern printing. This project demonstrates problem-solving, loop control, and pattern design without using external libraries.
# ❤️ Python Heart Pattern

This project prints a heart shape in the console using Python.

## Features

- Nested loops
- Conditional logic
- Coordinate-based pattern printing
- Adjustable heart size
- Beginner-friendly implementation

## Concepts Used

- for loops
- if conditions
- Variables
- Pattern printing
- Python fundamentals

## Output

Prints a heart-shaped pattern directly in the terminal.
